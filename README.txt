PORTOFOLIO WEB — HAFIZ RIZQI HERNANDA
Tema visual: Persona 5 inspired, berdasarkan video referensi yang dikirimkan.

STRUKTUR FILE
- index.html  : Struktur/konten halaman website.
- style.css   : Seluruh desain, warna, layout, animasi, dan responsivitas.
- script.js   : Navigasi halaman, kontrol keyboard, riwayat navigasi, dan tombol salin kontak.
- CV_Hafiz_Rizqi_Hernanda.pdf : CV yang dapat dibuka dari halaman Contact.

PENTING
Letakkan index.html, style.css, script.js, dan CV_Hafiz_Rizqi_Hernanda.pdf dalam folder yang sama. Jangan memindahkan satu file saja karena halaman membutuhkan file CSS dan JavaScript eksternal.

CARA MEMBUKA
1. Ekstrak ZIP terlebih dahulu.
2. Buka folder persona5-portfolio.
3. Klik dua kali index.html untuk membukanya di Chrome, Edge, atau Firefox.
4. Koneksi internet diperlukan untuk memuat Google Fonts. Website tetap berjalan dengan font fallback jika offline.

CARA DEPLOY KE GITHUB PAGES
1. Buat repository GitHub baru.
2. Upload seluruh isi folder ini (bukan hanya index.html).
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.

CATATAN DATA
- Konten portofolio disusun berdasarkan CV yang diberikan.
- Email pada CV tertulis "hafizhernanda5gmail.com" (tanpa karakter @). Nilai tersebut ditampilkan apa adanya; perbaiki setelah memastikan alamat email yang benar.
- Lokasi ditampilkan ringkas sebagai Tulungagung, Jawa Timur. Alamat lebih rinci tidak ditampilkan.
- Persentase tingkat keahlian tidak ditambahkan karena CV tidak mencantumkan penilaian tingkat kemampuan.
